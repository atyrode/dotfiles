# sops

Who may read the fleet's secrets, in the layout the `clan` CLI keeps
([docs/secrets.md](../docs/secrets.md) has the model and what a leak costs).
`users/<name>/key.json` and `machines/<name>/key.json` each hold an age
recipient and its type, nothing else, and the `secret-shapes` check refuses
anything more; `groups/admins/users/<name>` is a symlink per member of the
one group every value is encrypted to; `secrets/<host>-age.key/` holds a
machine's private key, encrypted to that group like any other value. The
values themselves are generated by clan vars into [`vars/`](../vars/README.md).

## One operator key per device

- `users/alex-<host>` is the operator on one device, minted there by
  `atyrode operator init` -- inside the Secure Enclave on a Mac, a plain age
  key elsewhere -- and never copied. Every member of `admins` holds the same
  authority; no device is special.
- `users/alex-recovery` is the software key whose only copy is the break-glass
  note in Bitwarden. It is a member from day one so that losing every device
  costs a recovery and nothing more; nothing in this repository reads it.

## The key on a machine

Clan mints a machine's key on whichever operator device runs
`clan vars generate <host>` first, keeps it under `secrets/<host>-age.key`
encrypted to `admins`, and records the public half under `machines/<host>`.
Both machine classes hold the private key at `/var/lib/sops-nix/key.txt`,
root-owned, mode 0600 under a mode-0700 directory; sops-nix is pointed at it
by [`modules/shared/clan-machine.nix`](../modules/shared/clan-machine.nix),
`atyrode apply` places it there on the machine the operator sits on, and
`clan machines update` places it over SSH.

## Ceremonies

Registration runs in any checkout of this repository; clan commits what it
writes, and the operator pushes.

Enrol a device:

```sh
atyrode operator init                            # on the device, once; prints the next two lines
clan secrets users add alex-<host> age1...       # writes users/alex-<host>/key.json
clan secrets groups add-user admins alex-<host>  # writes the group link; re-encrypts every value to the new member
```

Enrol a machine:

```sh
clan vars generate <host>                        # on an operator device; mints the machine key and its vars
atyrode apply                                    # on the machine; places the key, then activates
```

Retire a device, a machine, or a leaked key:

```sh
clan secrets groups remove-user admins alex-<host> && clan secrets users remove alex-<host>
clan secrets machines remove <host>              # then delete secrets/<host>-age.key and clan vars fix
```

`age-plugin-se` is declared to clan as `secrets.age.plugins` in
[`lib/configurations.nix`](../lib/configurations.nix), so clan's own `sops`
calls can decrypt with the Mac's enclave key on the Mac; the `security`
capability puts it on the Mac's `PATH` for everything else.
